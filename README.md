# ПНГ-А (Версия 0.0.2) 🎤✨

**ПНГ-А** — это кастомная покадровая студия для стримеров (PNGTuber софт), созданная на базе **PyQt6**. Программа в реальном времени анализирует ваш голос с микрофона и динамически переключает кадры аватара, оживляя вашего персонажа на трансляции. 

Интерфейс выполнен в уникальном тёмно-графитовом ретро-стиле с сочными оранжевыми пиксельными шкалами-кубиками.

## 🚀 Что нового в версии 0.0.2
* **Честная прозрачность для OBS:** Окно стрима теперь полностью прозрачное (использует альфа-канал ОС). Больше не нужно вырезать ядовито-зелёный хромакей в OBS и страдать от пиксельной «грязи» по краям аватара!
* **Полноценная 3-кадровая анимация:** Исправлена ошибка таймеров. Теперь аватар честно и плавно крутит циклы дыхания по всем 3-м кадрам покоя (`Idle`), речи (`Talk`) и крика (`Shout`).
* **Сглаживание и умная инерция:** Рот аватара больше не залипает в открытом состоянии, а при резком переходе от крика к тишине аватар на долю секунды переключается в фазу обычной речи для естественности.
* **Пиксельные слайдеры:** Абсолютно все ползунки параметров и звука перерисованы в виде винтажных пиксельных делений-кубиков.

## 📋 Инструктаж по настройке программы

### 1. Подготовка кадров (Скинов)
Для корректной работы вашего аватара вам понадобится сетка из PNG-картинок (желательно квадратных, например 500х500 пикселей) на прозрачном фоне:
* **Строка IDLE:** 3 кадра покачивания/дыхания персонажа с закрытым ртом.
* **Строка TALK:** кадры для обычной речи (рот открыт, рот прикрыт, рот закрыт + удивленные глаза для моргания во время разговора).
* **Строка SHOUT:** кадры для громкого крика/смеха (широко открытый рот).
* **Строка SLEEP:** кадры для AFK-режима (когда вы долго молчите, аватар засыпает).

Вы можете загрузить их по отдельности, кликая на ячейки таймлайна, либо нажать кнопку **UPLOAD FOLDER** и импортировать всю папку с картинками разом (программа автоматически отсортирует их по порядку).

### 2. Настройка звука и микшера
* Выберите ваш микрофон в выпадающем списке сверху.
* Двигайте вертикальный ползунок **Усиление (Gain)**, если ваш микрофон тихий.
* Настройте ползунок **Речь** так, чтобы шкала звука поднималась выше него только тогда, когда вы реально говорите.
* Настройте ползунок **Крик** на самый верхний порог вашего громкого голоса.

### 3. Вывод аватара в OBS Studio (Без хромакея!)
1. В программе нажмите кнопку **LAUNCH STREAM**. Появится отдельное окно с вашим аватаром.
2. Откройте **OBS Studio**.
3. Добавьте новый источник **«Захват игры»** (Game Capture) или **«Захват окна»** (Window Capture).
4. В выпадающем списке окон выберите: `Покадровая Студия — OBS Окно`.
5. **Критически важно:** Поставьте галочку на пункте **«Разрешить прозрачность»** (Allow Transparency) в настройках источника OBS.
6. Готово! Аватар отображается на вашем стриме с идеальными прозрачными контурами. Нижнюю панель управления окном зрители не увидят.
