# Покадровая Студия (Frame PNGTuber)

Стильное, минималистичное приложение для стримеров (PNGTuber), разработанное на **Python и PyQt6**. Позволяет анимировать 2D-персонажа в реальном времени, реагируя на голос с микрофона, а также поддерживает автоматическую смену скинов и запуск спецэффектов через интеграцию с наградами за баллы канала **Twitch**.

## ✨ Особенности
- **Интеллектуальный микшер:** Раздельная настройка порогов для покоя, обычной речи и крика.
- 
- **Интеграция с Twitch:** Автоматическая смена костюмов и наложение слоев анимации (FX) при покупке наград зрителями.
     (вообще это еще не проверяла) 

- **Массовая загрузка:** Удобное диалоговое окно для быстрого распределения готовых папок с кадрами по ячейкам таймлайна.

## 🚀 Как запустить (Для пользователей)
Если вы не хотите устанавливать Python, просто перейдите в раздел **Releases** справа, скачайте готовый архив, распакуйте его в любую папку и запустите `Покадровая_Студия.exe`.
